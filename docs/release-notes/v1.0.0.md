## 更新内容

MacUnblock 首个版本：把「解除安装限制」这件小事做成一个顺手的小工具。

- **拖拽即用**：把 `.app` / `.pkg` / `.mpkg` / `.dmg` / `.ipa` / `.appex` 拖到窗口，自动移除隔离属性，不再出现「已损坏 / 无法验证开发者」。
- **换一种入口**：也可以点拖拽区域或「选择文件…」挑文件，支持一次选多个、批量处理。
- **中英双语界面**：跟随系统「语言与地区」自动切换，中文系统显示中文、英文系统显示英文，无需手动设置。
- **进程内原生移除**：直接调用系统的扩展属性接口递归清理，不用子进程，不会遇到 `Operation not permitted`。
- **保留有用信息**：只清隔离属性，Finder 图标与标签等元数据不受影响。
- 通用架构（Apple 芯片 + Intel）安装包，纯本地运行、不联网。
